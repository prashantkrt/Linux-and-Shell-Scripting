In Linux shell prompts:

# → means you are logged in as root user (superuser).
$ → means you are logged in as a normal user.

Linux Users: Root vs Normal User

🔹 Root User
The root user is the administrative (superuser) in Linux.
Has full privileges: can install software, modify system files, manage users, and configure the system.
Prompt is usually shown as #.
Common Commands for Root
# pwd        # Print working directory (shows where you are)
# ls         # List files and directories
# uname      # Show system information (e.g., kernel name)
# whoami     # Show current logged-in user
# id         # Show user ID (UID) and group ID (GID)

Switch to root user
su -        # Switch user to root (requires root password)
sudo -i     # Switch to root user (requires current user's password)


🔹 Normal User
A normal user has limited permissions.
Cannot change system files or install software without sudo.
Typical usernames: prashant, raj, john, doe etc.
Prompt is usually shown as $.
Common Commands for Normal User
$ pwd        # Print working directory
$ ls         # List files and directories
$ whoami     # Show current logged-in user
$ id         # Show UID and GID


🔹 Move from $ (normal user) → # (root user)
$ su -        
- Prompts for the root password.
- Switches you fully into the root environment.

$ sudo -i   
- Prompts for your own user password (not root password).
- Works only if your user is in the sudoers group.

🔹 Move from # (root user) → $ (normal user)
1. Exit root session: 
# exit
or just press Ctrl+D.

2. Explicitly switch to a user (e.g., prashant):
# su - prashant
Now your prompt will be $ again.
