# Vi / Vim Command Notes
vi Visible Interface 
vim Improved Version of vi Visible Interface Model

Vim is a powerful text editor for Linux. Below are some basic commands and examples.

When you are in Vim and press i, you go into Insert Mode.
In Insert Mode, Vim behaves like a normal text editor:
You can type text freely.
You can press Enter/Return to move to a new line.
You can use Backspace to delete characters.

By default in Vim, the mouse is disabled. That means you can’t click to move the cursor (unless you enable it in settings).
Instead, Vim expects you to move the cursor using keyboard commands while in Normal Mode (not Insert Mode).

In Insert Mode (when you press i), Vim behaves almost like a normal text editor.
That means cursor movement is very limited — mostly with arrow keys and Enter.

Here’s what you can do in Insert Mode:
Moving the cursor in Insert Mode
← ↑ → ↓ (Arrow keys) → move left, up, right, down.
Enter/Return → move the cursor to a new line below.
Backspace → delete left and move cursor left.
Ctrl-h → same as Backspace.
Ctrl-w → delete previous word.
Ctrl-u → delete to the beginning of the line. Everything before the cursor on that line is deleted.
⚡ But you cannot use h, j, k, l, w, b, etc. (they only work in Normal Mode).

So usually the workflow is:
=>  Press i → insert some text.
=>  Press Esc → back to Normal Mode.
=>  Move cursor around with h j k l w b 0 $ etc.
=>  Press i again where you want to type.


Vim Modes and How to Enter Them
1. Normal Mode

The default mode when you open Vim.
Used for navigation, deleting, copying, pasting, etc.
If you’re ever lost, press Esc to get back here.

How to enter:
Press Esc (from any mode).

2. Insert Mode

Used for typing text, like a regular editor.
In Normal Mode, use these keys:
Command  | Action
---------|--------------------------------------------------------
i        | Insert before cursor
I        | Insert at beginning of line
a        | Append (insert after cursor)
A        | Append at end of line
o        | Open new line below and start insert
O        | Open new line above and start insert
cw       | Change word (delete + enter insert mode)
Exit Insert Mode: Press Esc.

Command-line Mode

For commands (save, quit, search, replace).
Starts with : at the bottom of Vim.

How to enter:
From Normal Mode, press : → type command (e.g., :wq).
: → file commands (save, quit, jump to line)
Exit Command-line Mode:
Press Esc before entering the command.
Command-line Mode (: at bottom)
Starts when you type : / ?.
Used for save/quit (:wq, :q!) or search (/word).

## 1. Open a File
$ vim filename.txt
- Opens filename.txt in Vim. Creates the file if it doesn't exist.

## 2. Modes in Vim
- Normal Mode: For navigation and commands (default)
- Insert Mode: For typing text. Press i to enter
- Command Mode: For saving, quitting, etc. Press : to enter

## Syntax
- Commands are case-sensitive
- Use Esc to return to Normal Mode from Insert or Command Mode
$ vi/vim [arguments] filename
- Arguments can include options like -R (read-only), +n (start at line n), etc.

## 3. Basic Navigation
h   Move left
l   Move right
k   Move up
j   Move down

Example:

## 4. Insert Text options
i   Insert before cursor                        # To begin typing before the cursor position. Starts insert mode just before the cursor.
I   Insert beginning of the current line        # To begin typing at the beginning of the current line
a   Append to the next word of the currentline  # Starts insert mode just after the cursor.
A   Append at the next word of the current line # Append at the end of the line. Moves cursor to the end of the line and enters insert mode.
o   Open new line before cursor                 # Open new line below the current line
O   Open new line after cursor                  # Open new line above the current line. Creates a new line above the cursor line, enters insert mode.

## 5. Save and Quit (first press Esc to enter Normal Mode) then type:
:w     Save file
:q     Quit
:wq    Save and quit
:q!    Quit without saving
:wq!   Force save and quit

Example:
:wq    Saves the file and exits Vim

## 7. Undo and Redo
u        Undo last change
Ctrl+r   Redo last undone change

## 8. Copy, Cut, and Paste
yy   Yank (copy) a line # copies the entire line where the cursor is located.
yw   Yank (copy) a word # copies the word starting from the cursor position.
y$   Yank (copy) to end of line # copies from the cursor position to the end of the line.
yG   Yank (copy) to end of file # copies from the cursor position to the end of the file.
ygg  Yank (copy) to beginning of file # copies from the cursor position to the beginning of the file.
p    Paste after cursor # pastes the copied text after the cursor position.
P    Paste before cursor # pastes the copied text before the cursor position.
dd   Cut (delete) a line # deletes the entire line where the cursor is located.
dw   Cut (delete) a word # deletes the word starting from the cursor position.
d$   Cut (delete) to end of line # deletes from the cursor position to the end of the line.
dG   Cut (delete) to end of file # deletes from the cursor position to the end of the file.
dgg  Cut (delete) to beginning of file # deletes from the cursor position to the beginning of the file.

Cut (Delete + Store) in Normal Mode
dd → cut the current line
ndd → cut n lines (example: 3dd cuts 3 lines starting from cursor)
dw → cut from cursor to the end of word (plus space)
de → cut from cursor to the end of word (excluding trailing space)
d$ (or D) → cut from cursor to the end of line
d0 → cut from cursor to the beginning of line
dG → cut from cursor to the end of file
dgg → cut from cursor to the beginning of file

Paste in Normal Mode
p → paste after cursor / below line (for line cuts)
P → paste before cursor / above line (for line cuts)

## 9. Search
/word   Search forward for word
?word   Search backward for word
n       Next occurrence
N       Previous occurrence

## 10. Replace
rX                Replace character under cursor with X
:%s/old/new/g     Replace all occurrences of old with new
:%s/old/new/gc    Replace all with confirmation

## 11. Open Multiple Files
$ vim file1.txt file2.txt

Switch between files:
:next   Next file
:prev   Previous file

## 12. Split Windows
:split filename    Horizontal split
:vsplit filename   Vertical split
Ctrl+w w           Switch between windows

## 13. Force Quit
:q!    Quit without saving

# Common Vim Commands Summary
Normal Mode commands → No Enter needed
Command-line Mode commands (:) → Enter required command. Any command that begins with : requires Enter to execute.
Basic Commands:
Shift + :        → enter Command-line mode (Normal Mode command)
Esc              → return to Normal mode (Any Mode command)
i                → enter Insert mode (Normal Mode command)
u                → undo last change (Normal Mode command)
Ctrl + r         → redo last undone change (Normal Mode command)
dd               → delete the current line (Normal Mode command)
yy               → copy (yank) the current line (Normal Mode command)
p                → paste the copied line below the current line (Normal Mode command)
P                → paste the copied line above the current line (Normal Mode command)
/word            → search for word in the file (Normal Mode command) example: /hello Meaning: Search from the cursor downwards (towards the end of the file) for the word.
?word            → search backward for word in the file (Normal Mode command) example: ?hello Meaning: Search from the cursor upwards (towards the beginning of the file) for the word.
n                → go to next occurrence of the searched word (Normal Mode command)
N                → go to previous occurrence of the searched word (Normal Mode command) example: After searching /hello, press n to go to the next occurrence of hello.
:%s/old/new/g    → replace all occurrences of old with new (Command-line Mode command) example: :%s/old/new/g Meaning: Replace all occurrences of old with new in the entire file.
:%s/old/new/gc   → replace all occurrences of old with new with confirmation (Command-line Mode command) example: :%s/old/new/gc Meaning: Replace all occurrences of old with new in the entire file, asking for confirmation before each replacement.

:w               → save the file (Command-line Mode command)
:q               → quit Vim (Command-line Mode command)
:wq              → save and quit Vim (Command-line Mode command)
:q!              → quit without saving (Command-line Mode command)

:next            → go to next file when multiple files are opened (Command-line Mode command)
:prev            → go to previous file when multiple files are opened (Command-line Mode command)

:$               → go to the end of the file (Command-line Mode command)
G (capital G or press Shift + g)         → go to the end of the file (Normal Mode command)
:1               → go to the beginning of the file (Command-line Mode command)
gg               → go to the beginning of the file (Normal Mode command)
:500             → go to line 500 (Command-line Mode command)
500G             → go to line 500 (Normal Mode command)

Miscellaneous:
:split filename  → open file in horizontal split (Command-line Mode command) example: :split filename.txt Meaning: Open filename.txt in a new horizontal split window.
:vsplit filename → open file in vertical split (Command-line Mode command)  example: :vsplit filename.txt Meaning: Open filename.txt in a new vertical split window.
Ctrl + w, then w → switch between split windows (Normal Mode command)

Commonsense Tips:
G → go to end of file
gg → go to beginning of file
$ → go to end of line
0 → go to beginning of line
b → go back one word
w → go forward one word

d/D → delete/cut
y → copy/yank
p/P → paste

Quick Summary:
Esc → Go to Normal mode (to run x, dw, dd, etc.)
i → Insert mode (type text)
: → Command-line mode (save, quit, search, etc.)
