sed stands for Stream Editor.

It is a command-line tool used to find, replace, insert, delete, or transform text in a file or input stream.

It reads input line by line (streaming) → applies operations → prints the result.

basic syntax:
sed [options] 'script' inputfile
Commonly used options:
-i : Edit files in place (makes backup if extension supplied)
-n : Suppress automatic printing of pattern space

sed -n 'p' file.txt # Print all lines
sed -n '2,5p' file.txt # Print lines 2 to 5
sed -n '3p' file.txt # Print only line 3
sed -n '1p;3p;5p' file.txt # Print lines 1, 3, and 5
sed -n '1p' file.txt # Print only line 1

-e : Add the script to the commands to be executed
sed -e 's/old/new/g' -e 's/old/new/gi' file.txt
-f : Add the contents of script file to the commands to be executed
Commonly used commands:
s/pattern/replacement/ : Substitute 'pattern' with 'replacement'
d : Delete the pattern space (line)

p : Print the pattern space
a\ : Append text after the current line
i\ : Insert text before the current line
y/source/destination/ : Transliterate characters in 'source' to 'destination'

/g : Global replacement in the line
/c : Change the whole line to new text
/gi : Case-insensitive global replacement
